How API Leads Works

API Leads lets you send customer requests (or "leads") from your third-party lead tools directly into your Job inbox. This means every new lead from your connected system will automatically appear in Job inbox, ready to be scheduled or followed up on.

After connecting your third-party leads to Job inbox:

- All leads from the API show in the API Leads channel in Job inbox.
- You can treat these just like any other Job inbox message: - Respond to customers
- Convert to a job or estimate
- Track the lead source for reporting

---

How to Enable API Leads in Job Inbox

Step 1: Enable API Leads in Housecall Pro

- Click the My Apps icon (3x3 square) in the top right corner of your Housecall Pro account.

- Select the Job inbox app to access your Job inbox settings.

Step 2: Get Access to the Public API

To connect your system, you’ll first need access to Housecall Pro’s Public API.

- If you’re a Pro who isn’t technical, don’t worry, just share this link with your developer or the person who manages your website: API Authentication Guide.

- This guide shows them how to "log in" to the API securely so your system can talk to Housecall Pro.

- Think of this step as giving your website or tool a key so it can drop new leads into your Job inbox.

Step 3: Send Leads into Job Inbox

Once your system has access, the next step is actually sending the customer info into Housecall Pro.

- Your developer will use something called the Create Lead connection in the API: Create Lead Guide.

- This is what takes the information from your third-party integration (when a customer provides their name and phone number) and automatically places it into the API Leads channel in Job inbox.

- After setup, every time a lead is created with your connected third-party tool, the customer’s details will appear in Job inbox, just like other integrated lead partners.

FAQs

Do I need a developer to set this up?

- If you’re comfortable working with APIs, you can do it yourself. Otherwise, share the API Docs with your web developer or integration partner.

Can I test before going live?

- Yes. The API Docs provide guidance for testing connections before sending live leads.

Will I see API Leads mixed in with other Job inbox leads?

- API Leads will appear in their own dedicated API Leads channel.
