Integrating CompanyCam and Housecall Pro

CompanyCam is a must-have app when working with homeowners, subcontractors, and other crews. The photo + video capture tools, automatic organization, and easy annotations make communicating with every stakeholder painless.

What does this mean for you? Well, for starters, it means:

- More organized jobs
- Fewer work photos on your phone
- Improved communication with clients

And that’s just scratching the surface!

How the Housecall Pro Integration Works with CompanyCam

- Create a new Estimate or Job in Housecall Pro.

- Choose a previously created customer. A new project in CompanyCam will be made for that customer if one hasn't been already created.

- Or create a new customer, and add multiple addresses, if needed. Each address will have its own CompanyCam project created at that point.

- Save the Estimate or job in Housecall Pro and it will receive photos and documents added to the CompanyCam project.

Please Note:

- The integration will not sync properly with CompanyCam if the First and Last name fields are not filled out on the Customer Profile, as CompanyCam requires this information.

- You can now have multiple CompanyCam projects created for the same Address.

- You can not sync photos back to jobs created before the integration was set up. A new Estimate or Job must be created to make the link back to Housecall Pro.

- CompanyCam Photos and Documents will sync to the ACTIVE Housecall Pro Estimate or Job. - Photos or documents added to a CompanyCam project will automatically sync to the active estimate or job linked to the project.

Creating a Project when you have an Existing Customer

If you're looking to create a project from existing customer information that was in Housecall Pro before you integrated with CompanyCam, you can use this simple process to push that information over:

- Go to the Customer profile for the customer who needs a project created for them.

- Click the pencil icon to edit Contact info.

[Image] https://downloads.intercomcdn.com/i/o/323868504/4118c213f074b219626787ed/companycam7.png?expires=1763567100&signature=a688401f0afa8eeecb40a14336b86a5c0bebe7d5e38df2af548ed8c6f1981262&req=dyIkHs92mIFbFb4f3HP0gB%2FOHhMooZpRPgkjFqgPLmBsYiUZ2U2zgyVv9x0o%0AnF1HCVuHc%2BKlO90sxg%3D%3D%0A

- You can edit any information in their Contact info and then choose Update. If you don't actually need to change any information, the simplest option would be to hit the + Email Button. You do not need to add an email address there, you simply need to click that button and then press Update.

[Image] https://downloads.intercomcdn.com/i/o/323868703/b45713cb1a8c8478442355d7/companycam8.png?expires=1763567100&signature=95e92033b21039bf767f517469fef0398d92b7c7e1bb305a65fe14621d96969e&req=dyIkHs92moFcFb4f3HP0gPM0A2L4l4DJY8imL7LGwGYLjGSKfpiUtvKzl1Bg%0AY27lUxdubR8E9vOigw%3D%3D%0A

Known Limitations of Integration

- Existing jobs on the schedule before integrating CompanyCam will not appear in CompanyCam. To get your pre-existing job to show up, simply edit the customer on that job (it could be as simple as hitting the +Email button). This change to the customer will trigger CompanyCam to update.

- Recurring jobs will not function properly; only the most recent occurrence will show up as a project in CompanyCam.
