Print Your Screen
Source: https://help.housecallpro.com/en/articles/120431-print-your-screen
Author: Nate H
Last updated: Updated over a month ago

Summary: Follow these steps to print a screen that does not have a print link.

In some cases, you might need to print a screen that doesn't have a direct print link or icon. This article provides a step-by-step guide on how to capture and print your screen effectively.

Please Note: Some HCP web pages do not allow information to be captured when using the 'Print' option directly from your browser.

Add the GoFullPage Screenshot Extension

As some HCP webpages don't allow information to be captured when using the 'Print' option directly from your browser, you'll first need to add a screenshot extension.

Please Note: Our recommended browser is Google Chrome. For the purposes of this Help Article, we will be going over how to add an extension to Google Chrome.

For printing your screen, we recommend using the GoFullPage extension. To add this extension, follow the steps below:

- First, go to the Chrome Web Store and search for the GoFullPage extension. - Chrome Web Store URL: https://chromewebstore.google.com/

Take a Screenshot and Print

Now that the GoFullPage extension has been added to your Google Chrome browser, you can take screenshots and print them as needed.

To do this in your Housecall Pro account:

- Navigate to a page that you'd like to print and click on the gray camera icon in the top right corner of your browser. You'll see a small window in the top right corner showing that the screen capture is in progress.
